# 格式与能力边界

当前最新独立表盘为 **R14 / `941006214`**，0.2.0 APK 仍内置 R13 / `941006213`。两者均面向小米 Watch S5 41mm / Q63 / 464×464，使用原生 `0x800` 表盘。该格式不能与 S5 46mm、其他小米型号、Vela 快应用、Wear OS XML 或手机网页的能力互相替代。

## 压力条件动画

**当前不支持“压力 >50 切换伤心坐姿动态图、≤50 恢复站姿动态图”。Q63 固件是否提供相应条件播放机制尚未证实。R14 仅修改熄屏 Q 版人物的袜子颜色，没有实现压力条件动画。**

研究到的可核对事实：

- [EasyFace 图片列表说明](https://github.com/m0tral/EasyFace/wiki/ImageListCN) 说明数据源与索引用于显示静态图片。
- [原始二进制格式模板](https://gist.github.com/Doliman100/c4d22766c4288ad0e025fb3eba066289) 的 image-list 引用 BitmapList，并提供 overwrite_index 数值映射。该模板来自另一型号的逆向，不能直接证明 Q63 的条件动画支持。
- [Mi8WfBinTool 原生编码源码](https://github.com/zhy8388608/Mi8WfBinTool/blob/main/Mi8WfBinTool.java) 中常规动画记录为 12 字节，含列表引用、帧间隔和循环次数；可编辑组及其他型号的 JS 分支不能作为 Q63 压力条件播放的证据。

本项目表盘后端也没有已验证的压力条件、数据驱动可见组或条件动画引用。已知动画按序播放；不能添加一个未经解释的字段，就认定固件会按压力自动切换。未知保留字节不等于可用功能，未找到机制也不等于证明所有固件永远不可能支持。

可以进一步研究 `0826` 压力源绑定静态图片列表，例如 0–50 指向站姿、51–100 指向伤心静态姿态。但此路径仍须单独扩展、隔离实验开关并验证 Q63，且不能满足“两套动态图自动切换”的要求。网页中通过条件表达式切换动画只构成模拟预览，不构成手表支持证据。

## R13／R14 数据与动画

R14 沿用 R13 的亮屏动态与排版。仅熄屏素材将面向观看者右侧的腿（人物左腿）改为白色过膝袜；R14 尚未真机安装。

两版使用独立原生数字组件：元气值 `182B`（用户选择今日新增）、压力 `0826`、心率 `0822`、天气摄氏气温 `2031`；四项数值无可见单位，标签和数字共用中轴 x=398。天气气温不是腕温。数据源含义、刷新周期及缺失值表示仍需在目标固件上分别核对，不能用截图示例当真实健康测量。

农历图片列表使用 `3012`／`3812`，闰月等 Q63 语义尚未完整核验。时间为 24 小时制。电量百分号作为原生数字单位图跟随位数；Q63 真机后缀行为仍需显示核验。

亮屏原生资源为 240 帧、17ms/帧，约 58.82fps，4.08 秒循环；数字与日期保持独立。图片使用共享调色板、不进行帧间淡入淡出，动画区域以不透明帧覆盖。构建像素回读和浏览器播放验证不能保证手表实测无掉帧。熄屏为静态低亮 Q 版人物，不播放动画。

## 连接与传输

经典蓝牙连接、SAR 分帧、应用层认证、MASS 文件传输、手表安装和应用确认是不同阶段。已配对或已扫描并不消除认证要求。App 仅接受目标身份，先尝试已有绑定；不将进入“连接新手机”作为每次使用的前置条件，不自动删配对或恢复出厂。

Android 中转负责传输与应用，不向原生表盘注入持续运行的网页代码，也没有后台监控压力再代替手表切换状态的功能。仅支持明确验证过的流程，未知型号和未经验证的字段不会被当作通用能力。
