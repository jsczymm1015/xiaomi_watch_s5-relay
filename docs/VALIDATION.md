## 已验证的历史连接后端

0.1.3 在一台目标设备上完成了本地连接信息导入、蓝牙／SAR 握手、认证、型号检查、R7／R8 安装及应用，并通过只读状态回读确认当前表盘。成功路径同时要求安装结果、应用响应和当前列表确认；不以扫描或文件发送完毕代替。

历史 Java 51 项覆盖独立 HMAC／AES-CCM／CTR 向量、Protobuf 边界、SAR 分帧／CRC／重传／回绕、MASS 续传、脚本化对端失败路径、合成日志导入边界、RFCOMM 兼容连接以及目标型号冲突拒绝。这些测试不代表所有手机、固件和小米型号兼容。

旧启动 instrumentation 未完成，不计通过。独立只读状态工具曾成功读取安装结果，且以自身包为目标，不重启传输中的中转 App、不注入点击；检查后测试工具已移除。手机系统拒绝远程输入的限制没有被绕过，导入和开始操作由用户在手机上完成。
